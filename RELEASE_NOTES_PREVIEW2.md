# Retro Relay Browser 2.0 — Windows Beta (v2.0.0-preview2)

This is an early Windows preview of Retro Relay Browser, a free gaming-focused desktop browser.

## Planned downloads

- **RetroRelayBrowser-Setup-2.0.0-preview2.exe** — installer for Windows 10 (64-bit)
- **RetroRelayBrowser.exe** — portable application for Windows 10 (64-bit)

## Preview features

Tabbed web browsing, customizable themes, gaming-related content and discovery, workspace features, and privacy controls. Some integrations and behaviors may be incomplete.
