# Retro Relay Browser

Retro Relay Browser is a free, gaming-focused web browser for Windows, with Linux support in development. It includes customizable themes, gaming news and discovery, privacy controls, resource-management features, and tabbed browsing.

## Windows beta — v2.0.0-preview2

**Current status:** Windows preview installer and portable executable have been built. The new repository's public download release is not yet published.

When the files have been uploaded and the beta is published, download them from [GitHub Releases](https://github.com/Cardsmageanime/RetroRelayBrowser/releases):

- **RetroRelayBrowser-Setup-2.0.0-preview2.exe** — Windows installer with shortcuts and uninstall support.
- **RetroRelayBrowser.exe** — Portable Windows application; does not install itself.

To install, download the Setup EXE, run it, and follow the installation wizard. This preview has not completed independent distribution/security testing; review Windows warnings before running an unsigned installer.

## Linux

Linux packaging and CI build scripts are in development. A Linux release will follow successful native compilation and desktop testing. Do not download a Windows EXE for Linux.
